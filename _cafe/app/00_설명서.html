꼭 지킬 것 3가지
  1. 카페 자동 등록(CafeAuto)은 PC 한 대에서만 켜 둡니다. 두 대에서 켜면 같은 글이 두 번 올라갑니다. 새 PC로 옮기면 예전 PC의 작업 스케줄러에서 CafeAuto·CafeRank를 꺼 주세요. 블로그·클립 예약도 같습니다.
  2. 네이버 로그인 정보와 API 키는 압축 파일에 들어 있지 않습니다. 로그인은 새 PC의 전용 창에서 직접 하고, 키는 따로 받습니다(00_빠진파일.txt 참고).
  3. 프로그램 폴더는 반드시 C:\autowin 바로 아래여야 합니다. 압축을 풀 때 C:\autowin\autowin\... 처럼 한 단계 더 생기지 않게 하세요.

2. 새 PC 설치 (순서대로)

① 파이썬 설치

  1. python.org → Downloads → Windows 용 최신 Python 3 설치 파일을 받습니다.
  2. 설치 첫 화면 아래 "Add python.exe to PATH"에 체크하고 "Install Now".
  3. 시작 메뉴에서 "명령 프롬프트"를 열고 py --version 입력 → 버전 숫자가 나오면 성공.

② 크롬 설치

전용 창은 PC에 설치된 크롬으로 엽니다. 크롬이 없으면 먼저 설치합니다.

③ 프로그램 넣기

  1. 받은 autowin_전달_날짜.zip을 오른쪽 클릭 → "압축 풀기".
  2. 안에 있는 autowin 폴더를 C:\ 바로 아래로 옮깁니다. → C:\autowin\post_cafe.py 처럼 보여야 정상.
  3. 따로 받은 API 키 파일이 있으면 C:\autowin에 넣습니다(00_빠진파일.txt에 적힌 이름 그대로).

④ 필요한 부품 설치

C:\autowin\00_필요한설치.txt를 열어 적힌 명령을 명령 프롬프트에 그대로 붙여 넣습니다. 예:

py -m pip install playwright requests
py -m playwright install chromium

⑤ 전용 창 열고 네이버 로그인

  1. C:\autowin\2_open_window.bat 더블클릭 → 크롬 창이 하나 뜹니다.
  2. 그 창에서 네이버에 로그인합니다(로그인 상태 유지 체크). 이 창은 끄지 말고 두세요.
  3. 카페 cafe.naver.com/mamn9 에 들어가 글쓰기 권한이 있는지 확인합니다.

⑥ 카페 예약 등록

  1. C:\autowin\12_cafe_schedule.bat를 오른쪽 클릭 → "관리자 권한으로 실행".
  2. SCHEDULE OK 가 나오면 끝. 매일 09:00(글 올리기)과 12:10(순위 확인)에 자동 실행되고, 절전 중이면 깨워서 실행합니다.

⑦ 시험 한 번

명령 프롬프트에서 py C:\autowin\cafe_test.py → 아직 안 올린 첫 글을 게시판·제목·본문·태그까지 채우고 등록은 누르지 않습니다. 화면을 보고 이상 없으면 직접 "등록"을 누르거나 창을 닫습니다.

⑧ 블로그·클립 예약

00_포함목록.txt에서 블로그·클립용 .bat 파일(예약 등록용 포함)을 찾아 같은 방식으로 등록합니다. 예전 PC의 작업 스케줄러(시작 → "작업 스케줄러")에 있던 작업 이름과 시각을 그대로 맞추면 됩니다.

3. 매일 확인할 것 (5분)

  • PC가 켜져 있고(절전은 괜찮음, 종료는 안 됨) 전용 창 로그인이 살아 있는지.
  • C:\autowin\cafe_log.txt 맨 아래 — "오늘 카페 글 시각", "완료: …" 줄이 3개 있으면 정상.
  • 점심 이후 C:\autowin\cafe_rank_요약.txt — 게시판별 노출 결과.
  • 글 폴더(C:\autowin\cafe_posts\c0xx_…)에 업로드완료.txt가 생기면 올라간 글, _실패.txt가 생기면 실패한 글입니다.

5. 블로그·클립 프로그램

블로그·클립 프로그램은 카페와 같은 C:\autowin에 있고 같은 전용 창을 씁니다. 프로그램별 설명과 실행 파일은 압축 파일과 함께 만들어진 00_포함목록.txt에 정리돼 있습니다(지금 PC에서 실제 쓰는 최종 파일 기준).

프로그램역할
post_blog.py네이버 블로그 글 발행
blog_top_posts.py, blog_stats.py, keyword_research.py블로그 인기글·방문자 기록·키워드 조사
upload_clip.py, make_clip.py, make_voice_clip.py네이버 클립 영상 만들기·올리기

카페 프로그램은 위 프로그램이 돌고 있으면 끝날 때까지 기다렸다가 올리므로, 시간이 겹쳐도 크롬 창이 엉키지 않습니다.

6. 문제 해결

증상 (cafe_log.txt / _log)할 일
전용 창이 안 떠 있습니다2_open_window.bat 실행 후 다시 시도
네이버 로그인이 풀렸습니다전용 창에서 다시 로그인, 실패한 글 폴더의 _실패.txt 삭제 → 다음 날 자동으로 다시 올림
게시판 '…'을 목록에서 못 찾았습니다카페 메뉴 이름이 바뀌었는지 확인 → 관리자에게 알려 cafe_config.json 수정
글쓰기 권한이 없습니다전용 창 계정의 카페 가입·등급 확인
실패하면 그날은 멈춤같은 오류 반복을 막으려는 동작입니다. 원인을 고치고 _실패.txt를 지우면 다음 실행 때 이어서 올립니다.
09:00에 아무 기록이 없음PC가 꺼져 있었거나 예약이 빠짐 → 12_cafe_schedule.bat를 관리자 권한으로 다시 실행
그 밖의 오류글 폴더의 _log 사진과 log.txt를 관리자(또는 Claude)에게 보여 주세요.

전달용 압축 파일 다시 만들기

프로그램이 바뀐 뒤 다시 전달하려면 지금 쓰는 PC에서 py C:\autowin\make_handoff.py 실행 → 바탕화면에 autowin_전달_날짜.zip이 생깁니다. 로그인 정보·기록·키 파일은 자동으로 빠지고, 이미 올린 카페 글은 "올림" 표시만 넣어 새 PC가 같은 글을 다시 올리지 않습니다.
