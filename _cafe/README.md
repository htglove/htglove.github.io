# 카페 자동 글쓰기 대기열 (폰안파는폰가게 · cafe.naver.com/mamn9)

이 폴더는 사이트에 공개되지 않는다(_로 시작). 매일 예약 작업이 새 글 3개를 여기에 넣고,
사용자 PC(C:\autowin)의 프로그램이 13:00 전에 내려받아 13:00~18:30 사이 랜덤 시각에 카페에 올린다.

## 폴더 구조
- index.json: 전체 글 목록 (folder, keyword, type, model, created, files). 새 글은 posts 배열 끝에 추가. 기존 항목은 고치거나 지우지 않는다.
- posts/<폴더>/post.json, card1.html, card2.html, img1.png, img2.png
- 폴더 이름: c + 3자리 번호(이어서) + _ + 영문 소문자·숫자·하이픈 (예: c004_galaxy-s26-spec). 한글 금지.
- tools/render.py: cardN.html → imgN.png 렌더링

## post.json 형식
{"keyword": "...", "title": "...", "body": ["문단", {"image": "img1.png"}, "문단", ...], "tags": ["띄어쓰기없는태그", ...]}
- body 문자열 하나 = 한 문단. 문단 안 줄바꿈은 \n. 소제목은 "■ "로 시작.
- {"image": "imgN.png"} 위치에 사진이 들어간다. 사진은 2장, 서로 떨어진 위치에.
- tags 4개, 띄어쓰기 없이. 1번 = 키워드 붙여 쓴 것.
- 분량: 문단 6~8개, 본문 900~1,300자.

## 키워드 규칙 (사용자 지정)
- 성지 내용 금지. 휴대폰·핸드폰 싸게 사는 법과 관련된 정보.
- 주력 4유형: 모델명+가격 / 모델명+스펙 / 모델명+자급제 / 모델명+유심기변.
  가끔(하루 최대 1개) 보조: 모델명 vs 모델명 비교, 모델명+출시일·사전예약(출시 예정폰), 휴대폰 싸게 사는법 계열.
- 하루 3개는 서로 다른 유형, 서로 다른 모델. 같은 키워드는 다시 쓰지 않는다(index.json 확인). 같은 모델은 3일 안에 반복하지 않는다.
- 현재 국내 판매 중인 모델을 고루 돌린다: 갤럭시 S26/S26+/S26 울트라, 갤럭시 Z 폴드·플립 최신, 갤럭시 A 시리즈(A37, A57 등), 아이폰 17, 아이폰 에어, 아이폰 18 프로/프로 맥스, 아이폰 17e 등. 판매 여부는 검색으로 확인.
- 키워드는 제목 맨 앞에 띄어쓰기 그대로 + 본문 첫 문단 첫 문장에 1회 그대로. 본문 전체 3~5회.

## 내용 규칙
- 가격·스펙·출시일·정책은 반드시 웹 검색으로 확인한 최신값만 (제조사·통신사 공식, 주요 언론). 확인 못 한 수치는 쓰지 않는다. 본문에 "(2026년 M월 확인)"처럼 기준 시점 표기.
- 2026-10-01 갤럭시 S26 시리즈 출고가 14만9,600원 인상, 2026-09-10 아이폰 17 가격 인상(256GB 145만 원)·아이폰 17 프로/프로 맥스 애플 공식 판매 종료 등 최근 변동을 반영(재확인).
- 본문 끝에 출처 목록·고지 문구를 넣지 않는다. 브랜드(폰안파는폰가게) 홍보 문구는 넣지 않는다.
- 과장·재촉 표현 금지: 최저가, 무조건, 100%, 역대급, 지금 바로, 선착순, 공짜(근거 없이).
- 다른 매장·업체 비방 금지.
- 마지막 문단은 댓글로 질문 유도 등 자연스러운 마무리, 매번 문장을 다르게.
- 반복 콘텐츠 제재를 피하기 위해 구성을 매번 바꾼다: 표·목록형, Q&A형, 계산 예시형, 상황별 추천형, 순서 안내형, 비교형 등. 같은 날 3개 글은 구성도 서로 다르게. 첫 문장 패턴도 매번 다르게.

## 이미지 규칙 (card1.html, card2.html → img1.png, img2.png)
- 코드로 만든 정보 카드(무료). 너비 1080px 고정, 높이는 내용대로(700~1100px). 글꼴 'Noto Sans CJK KR'.
- 글마다 2장, 서로 다른 레이아웃. 매번 배경색·포인트색·레이아웃을 바꿔 이전 글들과 비슷해 보이지 않게(최근 posts의 card html을 보고 피한다).
  레이아웃 예: 가격표, 큰 숫자 계산, 2열 비교, 세로 타임라인, 체크리스트, 증상→해결 표, 스펙 아이콘 그리드, 질문 카드, 막대 비교 등.
- 제품 사진·로고·다른 사이트 이미지 금지. 이모지 금지(✓ 같은 기호는 가능). 글자 대비 충분히.
- <!doctype html> 로 시작(표 글자색 문제 방지). 외부 리소스 불러오지 않는다.
- 렌더링 후 이미지를 직접 열어 글자 겹침·잘림·안 보이는 글자가 없는지 확인하고 고친다.
